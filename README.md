# 💍 WedPlan – Wedding Planning Portal

> Plan your perfect wedding, all in one place!

WedPlan is a responsive wedding planning web application designed to help couples organize their wedding preparations with ease. It provides tools to manage budgets, vendors, guest lists, RSVPs, wedding checklists, and event timelines through a beautiful and user-friendly interface.

## 🌐 Live Demo

**Live Website:** [WedPlan Wedding Planning Portal](https://vanshika2723.github.io/WedPlan-Wedding-Planning-Portal/)

**GitHub Repository:** [View Source Code](https://github.com/vanshika2723/WedPlan-Wedding-Planning-Portal)

## ✨ Features

- 🏠 **Home Page:** Elegant wedding-themed landing page.
- 📊 **Dashboard:** Overview of wedding planning progress.
- 💰 **Budget Planner:** Add expenses, categorize spending, and track the remaining budget.
- 🏪 **Vendor Directory:** Browse vendors by category, search, sort, and view vendor details.
- 👥 **Guest Management:** Add guests, manage RSVP statuses, and organize seating information.
- ✅ **Wedding Checklist:** Create tasks, mark them complete, and monitor progress.
- 🗓️ **Wedding Timeline:** Organize important events and their schedules.
- ⏳ **Wedding Countdown:** Track the time remaining until the wedding.
- 💬 **Message Board:** Keep wedding-related notes and messages organized.
- 🔐 **Demo Authentication:** Simulated login and registration interface.
- 🌙 **Dark Mode:** Switch between light and dark themes.
- 📱 **Responsive Design:** Designed for desktop, tablet, and mobile screens.
- 💾 **LocalStorage:** Save supported planning data in the browser.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vanshika2723/WedPlan-Wedding-Planning-Portal.git
```

### 2. Open the project folder

```bash
cd WedPlan-Wedding-Planning-Portal
```

### 3. Run the application

Open `index.html` in your browser. You can also use the VS Code Live Server extension for local development.

No backend server or database is required for this frontend project.

## 💾 Data Storage

WedPlan uses browser LocalStorage to retain supported wedding planning information. The data is stored locally in the browser and is not automatically synchronized across devices.

The login and registration interface is a demonstration and does not provide production-grade authentication.

## 🎯 Project Objective

The objective of WedPlan is to simplify wedding organization by bringing essential planning tools into a single, accessible, and responsive web application.
